# Week 4 – Tokenizers

## Overview
This folder contains a tokenizer comparison exercise. The Python script visible in the project is `tokenizer_comparison.py`.

## Files
- `tokenizer_comparison.py` – tokenizer comparison script.
- `requirements.txt` – Python dependencies.

## Setup
Activate the shared virtual environment from the project root:

```powershell
& "C:\Users\praks\Downloads\GEN-AI\.venv\Scripts\Activate.ps1"
```

Install dependencies:

```powershell
python -m pip install -r requirements.txt
```

## Run
From this folder:

```powershell
python tokenizer_comparison.py
```

## Troubleshooting
This folder does not show a `main.py` file. Running `python main.py` will therefore fail with a file-not-found error. Run `tokenizer_comparison.py` instead.

## Notes
The exact tokenizers, input examples, and comparison metrics depend on the implementation in `tokenizer_comparison.py`.
