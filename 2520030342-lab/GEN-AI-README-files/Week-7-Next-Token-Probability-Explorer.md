# Week 7 – Next-Token Probability Explorer

## Aim
To use the GPT-2 language model to inspect the probability distribution of possible next tokens for given text prompts.

## Description
This program loads the GPT-2 model (`openai-community/gpt2`) using Hugging Face Transformers. For each prompt, it tokenizes the input, obtains the model's logits for the final input position, applies Softmax to convert the logits into probabilities, and displays the five highest-probability next-token candidates.

The program also saves the results to `week7_probability_results.csv`.

## Prompts Used
- `The cat is`
- `Artificial intelligence is`
- `India is a`
- `Machine learning helps`

## Files
- `main.py` – Loads GPT-2 and calculates next-token probabilities.
- `requirements.txt` – Lists the required Python packages (`torch` and `transformers`).
- `week7_probability_results.csv` – CSV file generated by the program containing prompts, ranks, candidate tokens, token IDs, and probabilities.

## Requirements
- Python 3
- PyTorch
- Hugging Face Transformers
- Internet connection for the initial GPT-2 model download

## Working
1. Load the GPT-2 tokenizer and causal language model.
2. Tokenize each input prompt and obtain its input token IDs.
3. Pass the tokenized input to GPT-2.
4. Extract the logits at the final input-token position.
5. Apply Softmax to convert logits into probabilities.
6. Select the top five candidates using `torch.topk`.
7. Decode and display each candidate token with its probability.
8. Save all results in `week7_probability_results.csv`.
