# Week 5 – Token Economics

## Overview
This folder contains a token-budgeting exercise. The visible project files include `budget.py` and `test_budget.py`.

## Files
- `budget.py` – token budget program/module.
- `test_budget.py` – tests for the budget code.
- `requirements.txt` – Python dependencies.
- `.env` – local configuration, if required.
- `__pycache__/` – Python-generated cache files.

## Setup
Activate the shared virtual environment from the project root:

```powershell
& "C:\Users\praks\Downloads\GEN-AI\.venv\Scripts\Activate.ps1"
```

Install dependencies:

```powershell
python -m pip install -r requirements.txt
```

## Run the program
From this folder:

```powershell
python budget.py
```

## Run the tests
```powershell
python test_budget.py
```

## Notes
The exact budgeting rules, inputs, and outputs are defined in `budget.py`. The test cases and expected behavior are defined in `test_budget.py`.
